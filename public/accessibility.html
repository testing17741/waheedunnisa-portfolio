Accessibility Statement

Commitment to Web Content Accessibility Guidelines (WCAG) 2.1 Level AA conformance.

1. Measures Taken for Accessibility

To ensure all students, researchers, and visitors—including those using assistive technologies—can access academic content seamlessly, this site incorporates:

  • Semantic HTML5 Structure: Proper landmark elements (<header>, <nav>, <main>, <article>, <footer>) and hierarchical headings (single H1 per page).
  • Keyboard Operability: All interactive components (navigation toggles, citation copy tools, modal dialogs, and mind map tabs) are accessible via standard Tab, Enter, Space, and Escape keyboard controls.
  • Color Contrast Standards: All text and active UI elements satisfy WCAG AA contrast thresholds (minimum 4.5:1 for standard body text, 3:1 for large headings) in both light and dark themes.
  • Skip Navigation Link: A dedicated skip-link at the top of every document allows keyboard users to bypass header navigation directly to main content.
  • Touch Target Sizing: All buttons, inputs, and interactive pills meet or exceed the 44px by 44px touch target requirement.
  • Reduced Motion Support: The stylesheet detects prefers-reduced-motion and eliminates non-essential transition animations.

2. Feedback & Assistance

If you encounter any difficulty navigating or accessing research documents on this site, please submit an inquiry through the Contact Page.
